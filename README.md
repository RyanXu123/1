## 目录

| 位置 | 装什么 |

## 怎么跑

```bash
gcc -Wall -Wextra -o out.exe 要跑的文件.c
./out.exe
```

`-Wall -Wextra` 是习惯：让编译器把可疑的地方全喊出来，不靠运气。

## 闸门补充（2026-10-02）

**发出去的 `.c` 也要过闸门**，不能只把关聊天草稿：

```
node <本机路径>\.codex\tools\lesson-gate.mjs --file <要发的 .c>
```

`lesson-gate` 的盲区：它认不出 printf 的**宽度修饰**（`%2d`、`%-5s` 这种）。
这类只能自己扫一遍 `printf` 里的 `%`。
2026-10-02 本座在 `demo\p38_strdigits.c` 里写了没讲过的 `%2d`，被主人当场抓包，已改回 `%d`。

## 高难概念的备课清单（2026-10-07 定）

主人原话：「以后像这样高难的任务，要准备充足。」

背景（题十二 · 环形缓冲）：第一轮只发了讲义 `.md` + 示例 `.c`，主人回「只看代码我可能看不懂」；
第二轮补了一大段文字，主人还是把「从旧到新」听成「从小到大」；第三轮才靠一张能点着走的图收住。
三轮才通，就是备课没到位，不是他跟不上。

以后凡是**建立心智模型**的课（不是补语法，是新概念），发布前先过这四条：

1. **先写一句「最容易搞混的地方」**：这个概念在脑子里最容易长歪的那根枝，讲义第一段就点破。
   （例：从旧到新 ≠ 从小到大；读走 ≠ 把值抹掉。）
2. **配一张能点着走的图**：`.md` 管文字、示例 `.c` 管能跑，两者都要主人自己在脑子里演一遍；
   概念型的必须再加一个可视化页面，把「物理摆法」和「逻辑顺序」这类对照直接摆出来。
3. **对照着放**：同一时刻两种视角并排显示（格子里怎么摆 / 按顺序怎么念），不要只在文字里描述。
4. **发完自查**：同一处被主人连问两轮，就是第一次没备好，回头补课不许催他。
